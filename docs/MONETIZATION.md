# Dugout Lab 유료화 전략

작성 기준일: 2026-08-22

> 이 문서는 사업 가설과 제품 설계안입니다. 법률·세무 자문이 아니며, 결제 기능을 열기 전 데이터 제공자와 국내 법률 전문가의 검토가 필요합니다.

## 결론

Dugout Lab은 `적중 보장 픽 판매`가 아니라 **경기 전 데이터 변화와 예측 근거를 보여주는 야구 분석 SaaS**로 판매하는 것이 적합합니다.

현재 4명 사용 단계에서는 결제 기능보다 경기 전 스냅샷과 실제 결과를 축적하는 것이 우선입니다. 특히 현재 수집 방식 그대로 KBO·MLB 데이터를 유료 서비스에 쓰면 데이터 이용 조건 문제가 생길 수 있으므로, **데이터 라이선스 확인 전에는 비공개 베타 또는 무료 검증판으로만 운영**하는 것을 권장합니다.

## 가장 현실적인 수익모델 순서

### 1. B2C Pro 구독

가장 먼저 검증할 모델입니다. 무료 사용자는 오늘 경기의 기본 승률과 대표 스코어를 보고, 유료 사용자는 경기 직전 업데이트와 깊은 분석을 사용합니다.

| 등급 | 월 가격 가설 | 제공 범위 |
|---|---:|---|
| Free | 0원 | 오늘 경기, 기본 승률·대표 스코어, 제한된 예측 근거 |
| Pro | 6,900~9,900원 | 선발·라인업 변경 재예측, BvP, 이닝별 시뮬레이션, 전체 근거, 예측 이력·성능 |
| Pro+ | 14,900원 | 시장 변동 알림, 사용자 임계치, 모델 비교, CSV 내보내기·웹훅 |

처음에는 Pro 한 등급만 두고 `월 9,900원`을 가격 가설로 테스트하는 편이 단순합니다. 사용자가 4명이면 월 매출은 39,600원으로, 가격 지불 의향을 확인하는 데는 의미가 있지만 상용 데이터 라이선스와 운영 인건비를 감당하는 사업 규모는 아닙니다.

### 2. 시즌 패스

야구는 시즌성이 강하므로 월 구독을 꺼리는 사용자에게 적합합니다.

- KBO 시즌 패스: 39,000원 가설
- KBO+MLB 통합 시즌 패스: 59,000원 가설
- 첫 시즌은 얼리어답터 가격으로 판매하고 갱신율을 확인합니다.

### 3. 크리에이터·커뮤니티용 B2B 위젯

야구 커뮤니티, 블로그, 방송 제작자가 자신의 페이지에 오늘 경기 카드·변화 알림·모델 성적표를 삽입하도록 제공합니다.

- 소형 커뮤니티: 월 10만~30만원 가설
- 브랜딩 제거·맞춤 디자인: 월 30만~50만원 가설
- 원시 데이터를 재판매하지 않고, Dugout Lab의 분석 결과와 화면을 제공하는 형태로 제한합니다.

### 4. 맞춤 분석·리포트

라이선스가 정리되기 전에도 비교적 안전하게 검증할 수 있는 모델입니다. 고객이 제공하거나 적법하게 라이선스한 데이터를 바탕으로 대시보드·모델·리포트를 제작합니다.

- 일회성 분석 리포트: 건당 30만~100만원 가설
- 맞춤 대시보드·모형: 건당 100만~200만원 이상 별도 견적
- 가격은 개발 시간, 데이터 정제 범위, 재사용 권한에 따라 결정합니다.

### 5. 분석 API

장기 후보입니다. 데이터 재배포 권리가 명확해진 뒤에만 출시합니다. 원시 기록이나 시장 배당을 전달하는 API가 아니라 `자체 계산한 확률·구간·모델 설명`을 제공하더라도 원천 데이터 계약에서 파생 결과의 재배포 범위를 확인해야 합니다.

### 6. 광고·스폰서십

트래픽이 충분해진 뒤의 보조 수익원입니다. 초기에는 광고가 사용자 경험을 해치고 매출도 작을 가능성이 큽니다. 불법 사설 도박 사이트, 적중 보장 서비스, 회원 모집형 광고는 받지 않습니다.

무료판도 모델의 실제 과거 성적과 면책 문구를 숨기지 않습니다. 유료의 가치는 확률을 과장하는 데 있지 않고 **더 빠른 업데이트, 더 깊은 근거, 변화 추적, 개인화**에 둡니다.

## 결제 전에 통과할 조건

1. `T-24h`, `T-3h`, `T-60m`, `T-15m` 경기 전 예측과 실제 결과를 빠짐없이 저장합니다.
2. 평가 가능한 경기 200개부터 예비 성적을 공개하고, 최소 500개에서 첫 유료화 여부를 판단합니다.
3. 동일 경기에서 현 모델, 단순 홈 승률, 시장 컨센서스를 날짜순 walk-forward로 비교합니다.
4. 20~30명의 비공개 사용자를 모집해 어떤 기능에 돈을 낼지 인터뷰·설문·사용 로그로 검증합니다.
5. 유료 전환 의향과 4주 재방문율이 확인되면 데이터 제공자에게 상업 이용·저장·파생 결과 표시·재배포 범위를 서면으로 확인합니다.
6. 그 다음에 이용약관, 개인정보 처리방침, 환불 규정, 결제, 계정·권한 기능을 구현합니다.

권장 초기 지표는 주간 재방문율, 라인업 확정 후 재접속률, 알림 클릭률, Pro 체험 전환율, 유료 전환율, 2개월차 유지율입니다. 단순 페이지뷰보다 `경기 전 업데이트를 다시 확인하는 행동`이 제품 가치에 더 가깝습니다.

## 데이터 라이선스와 법적 체크포인트

### KBO

[KBO 이용약관](https://www.koreabaseball.com/Etc/Policy.aspx)은 사전 서면 동의나 공식 API 없이 자동화 수단으로 데이터를 대량·반복 수집하는 행위, 수집 데이터의 재판매·재배포·타 플랫폼 연동·2차 가공 활용, 게시 자료의 상업적 이용을 제한합니다. 따라서 현재 KBO 웹 수집기는 개인 검증용으로 보고, 유료 서비스 전에는 KBO·스포츠투아이 또는 허가된 공급자와 서면 계약을 맺거나 적법한 상용 피드로 교체해야 합니다.

### MLB

[MLB 이용약관](https://www.mlb.com/official-information/terms-of-use)은 MLB 디지털 자산을 개인적·비상업적 용도로 사용하는 범위를 기본으로 두며, 복제·파생물·배포·표시에는 서면 허가가 필요할 수 있다고 밝힙니다. Stats API나 Baseball Savant가 기술적으로 접근 가능하다는 사실만으로 상업적 재사용 권리가 생기는 것은 아니므로, 유료화 전에 별도 허가 또는 상용 데이터 계약을 확인해야 합니다.

### 시장 기준점

[The Odds API 이용 조건](https://the-odds-api.com/terms-and-conditions.html)은 웹사이트·앱·대시보드·분석 도구에서의 상업적 사용을 허용하지만, 데이터를 주 상품인 원시 피드·다운로드·자체 API 형태로 재판매하는 것은 금지합니다. 현재처럼 분석 화면의 비교 기준으로만 보여주고 API 키를 서버에서 보호하는 방향이 적합합니다. 구체적인 상품 형태는 출시 전에 제공자에게 서면 확인합니다.

### 서비스 표현과 운영

- `적중 보장`, `수익 보장`, `확실한 경기` 같은 표현을 쓰지 않습니다.
- 사용자의 돈을 받아 결과에 따라 배당하거나 환급하지 않습니다.
- 불법 베팅 운영자 링크, 회원 모집, 수익 공유형 추천은 하지 않습니다.
- 확률과 성능에는 평가 표본 수, 기준 시점, 모델 버전을 함께 표시합니다.
- 서비스 약관에는 정보 제공용 통계 추정이며 결과·수익을 보장하지 않는다는 점을 명시합니다.
- 정식 출시 전 국내 스포츠 데이터·사행행위·광고 관련 법률 검토를 받습니다.

## 예상 비용과 손익 판단

4명 비공개 테스트는 기존 Oracle VM·SQLite·CPU 모델로 거의 무료에 가깝게 운영할 수 있습니다. 실제 유료화에서 큰 비용은 GPU가 아니라 **상업용 데이터 라이선스, 결제 수수료, 알림, 개인정보·보안 운영**입니다.

| 비용 | 검증 단계 | 유료 서비스 단계 |
|---|---|---|
| 서버 | Oracle 무료 한도 또는 소형 VM | 트래픽·백업에 따라 증설 |
| 통계 모델 | CPU로 충분 | CPU 배치 학습으로 대부분 충분 |
| 시장 데이터 | 무료 한도 내 제한 수집 가능 | 호출량 증가 시 유료 요금제 |
| KBO·MLB 데이터 | 비공개 검증만 | 상업 이용 계약 확인 필수 |
| LLM | 사용하지 않아도 됨 | 뉴스 구조화·설명 생성량만큼 발생 |
| 결제 | 없음 | PG 수수료·환불·세무 처리 |
| 알림 | 화면·이메일 최소화 | 문자·카카오·푸시 서비스 비용 |

`4명 × 월 9,900원` 수준에서 데이터 계약을 먼저 맺기보다, 무료 비공개 베타로 정확도와 지불 의향을 확인한 다음 계약 견적과 예상 유료 사용자 수로 손익분기점을 다시 계산해야 합니다.

## 90일 실행안

### 1~30일: 신뢰성 검증

- 데이터 누락·지연 대시보드와 경기 전 스냅샷 완성도를 확인합니다.
- 실제 결과와 모델별 Brier Score, Log Loss, 득점 MAE·RMSE, calibration을 공개합니다.
- 10명 안팎의 비공개 테스터에게 매일 사용하게 하고 불편을 기록합니다.

### 31~60일: 상품 가치 검증

- Free/Pro 화면을 기능 플래그로 구분하되 실제 결제는 받지 않습니다.
- `월 6,900 / 9,900 / 14,900원` 가격 문구를 번갈아 보여 클릭·신청 의향을 측정합니다.
- 가장 자주 쓰는 기능이 라인업 재예측, 알림, BvP, 이력 중 무엇인지 확인합니다.

### 61~90일: 출시 가능성 결정

- 평가 경기 수와 후보 모델 개선 폭을 확인합니다.
- 데이터 제공자에게 유료 서비스 시나리오와 필요한 권리 범위를 제시하고 견적을 받습니다.
- 예상 유료 사용자 수로 라이선스·서버·결제 비용을 충당할 수 있을 때만 결제를 구현합니다.
- 조건이 맞지 않으면 B2C 판매를 미루고 고객 제공 데이터 기반 맞춤 분석으로 먼저 매출을 검증합니다.

## 하지 않을 것

- 표본이 작은 적중률만 크게 홍보하기
- 경기 후 정보를 경기 전 데이터처럼 섞기
- 무료 웹페이지를 무단 스크래핑해 유료로 재판매하기
- 원시 배당 피드나 제공자 API를 그대로 재판매하기
- 사용자 손실에 연동되는 수수료·픽 판매·불법 사이트 제휴
- 정확도 검증 전에 고가 연간 구독을 선결제 받기
